# FlacFix

Tidy folders of FLAC albums on macOS: artist/album tags, clean track names,
embedded cover art (from the folder or iTunes) and Finder icons.

## Install

    brew tap OWNER/flacfix
    brew install flacfix

Then run `FlacFix` for the help screen, or `FlacFix ~/Music/SomeArtist`.
See `FlacFix-Guide.txt` (installed under `$(brew --prefix)/share/flacfix/`).

macOS only. Needs the Xcode command line tools (Homebrew already requires them).
